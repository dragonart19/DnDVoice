# D&D Proximity Voice

Tavolo virtuale per D&D con accesso Discord, voce di prossimità, attenuazione
attraverso muri e porte, gruppi vocali privati e mappa condivisa.

## Aprire il progetto

Il progetto Unity si trova nella cartella `DnDVoice`.

1. Installa Unity `6000.3.8f1`.
2. In Unity Hub scegli **Add project from disk**.
3. Seleziona la cartella `DnDVoice` contenuta in questa repository.

Le cartelle generate da Unity e le build Windows non sono incluse nella
repository. Unity le ricrea automaticamente al primo avvio.
